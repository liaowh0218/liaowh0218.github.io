# liaowh0218.github.io

Personal website of Wei-Hung Liao: <https://liaowh0218.github.io/>

A static site hosted on GitHub Pages. The pages are generated from `content.md` by `build.py`
(plain Python, no dependencies); `assets/style.css` holds the layout and colors.

```bash
python3 build.py    # regenerate the HTML from content.md
```
